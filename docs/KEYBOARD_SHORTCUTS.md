# Keyboard Shortcuts & Mouse Controls

> Shortcuts pause automatically whenever focus is inside a text input, textarea, select dropdown, or editable element.

## Global & Navigation

| Shortcut | Action |
| --- | --- |
| `Ctrl+K` / `⌘K` | Open Command Palette |
| `?` | Toggle Help & Keyboard Shortcuts overlay |
| `,` | Open Application Settings |
| `O` | Choose 3D Scan (`.glb/.gltf/.obj/.stl/.ply`) or `.json` Plan File |
| `1` | Go to Step 1 (Load) |
| `2` | Go to Step 2 (Orient) |
| `3` | Go to Step 3 (Edit) |
| `4` | Go to Step 4 (Export) |
| `Esc` | Cancel active tool / Clear selection / Close top modal |

## 2D Blueprint Editor (Step 3)

| Shortcut / Input | Action |
| --- | --- |
| `V` | **Select / Wall Handles / Marquee Box** tool (drag empty canvas to box-select; drag selected wall endpoints to resize) |
| `H` | **Pan / Hand** tool |
| `Space + Drag` | Temporary Pan anywhere on the canvas |
| `Middle-Click + Drag` | Pan canvas |
| `Mouse Wheel` | Zoom in / out at cursor |
| `D` | **Draw Wall Chain** tool (continuous polyline; double-click, right-click, or `Esc` to finish) |
| `Shift+D` | **Place Door Symbol** tool (snaps to nearest wall) |
| `W` | **Place Window Symbol** tool (snaps to nearest wall) |
| `A` | **Place Archway / Opening** tool (snaps to nearest wall) |
| `S` | **Place Stairs** tool (treads + `UP` arrow) |
| `M` | **Measure Distance** tool (2 clicks) |
| `C` | **Calibrate Scale** tool (2 clicks across known length) |
| `T` | **Add Text Note** tool |
| `E` | **Erase / Marquee Erase** tool (click item or drag red box to batch-erase) |
| `Alt` (hold) | Bypass endpoint, midpoint, and grid snapping while drawing/measuring |
| `Space` (tap) | Flip selected door swing (or rotate selected window 90°) |
| `Double-Click` (text note) | Edit note text inline |
| `Double-Click` (door/window) | Flip door swing / rotate window 90° |
| `Right-Click` | Cancel active rubberband wall/measurement/calibration |
| `R` | Rotate active floor plan 90° clockwise |
| `Shift+R` | Auto-Straighten walls to horizontal/vertical axes |
| `F` | Fit active floor plan to view |
| `+` / `=` | Zoom in |
| `-` / `_` | Zoom out |
| `Ctrl+Z` / `⌘Z` | Undo last edit on active floor |
| `Ctrl+Y` / `⌘Shift+Z` | Redo edit on active floor |
| `Delete` / `Backspace` | Delete selected item(s) |
